# 长期吃药预防，为什么还会得脑梗？

> 更新时间：2026-09-11 (UTC+8)

**01**

**案例背景**

Case Background

老张今年70岁，有高血压、阵发房颤，药物控制血压挺理想的。还长期持续吃着阿司匹林，想着预防心脑血管梗死，可突然间就得了脑梗，一侧肢体不能动了。

**Q**

**所以老张，为什么还会得脑梗？**

**A**

这次脑梗是阵发性房颤所导致的心源性血栓形成，“阿司匹林”不管用，需要换用“抗凝药物”才能有效避免心源性脑梗死！

“阿司匹林”是大家耳熟能详的药物，很多人都知道这种药物有**抗血栓**形成的作用。但阿司匹林是通过抑制血小板聚集，起到预防和治疗动脉血栓形成的作用，特别**适用于缺血性心脑血管疾病的患者**，有降低心肌梗死、脑梗死的发病风险以及预防心肌梗死、脑梗死复发的作用。

临床上，**房颤是最常见的快速性心律失常之一**，**合并高血压的比例超70%**；高血压合并房颤不仅可能**恶化心脏功能**，更进一步**增加房颤患者的****血栓栓塞****风险**，导致急性脑梗塞，甚至肾梗死、脾梗死等多脏器血栓栓塞发生。**在房颤患者中，合并高血压者脑梗死的发生风险增加2倍**。

**02**

**案例分析**

Case Analysis

像老张这样，70岁的**高血压合并房颤患者**来说，患者的**CHA2DS2-VASc评分至少2分**，依据现有的房颤治疗指南推荐对于**评分≥2分**的患者应考虑**抗凝治疗**，而不是吃阿司匹林（阿司匹林不具备抗凝作用）。新型口服抗凝药物（达比加群、利伐沙班和艾多沙班等）是优于华法林的选择，可作为房颤患者血栓栓塞预防的首选药物。
