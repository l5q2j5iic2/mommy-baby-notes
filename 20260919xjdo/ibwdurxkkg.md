# 治内膜异位症是选浙江新华医院好还是浙一医院好！费用情况怎么样！

> 更新时间：2026-09-19 (UTC+8)

杭州的浙中医大二院和浙一医院都有看子宫内膜异位症比较权威的医生，而这两家医院在妇产科以及生殖领域都是比较有影响力的，实力都比较强，在药物治疗子宫内膜异位症方面积累了丰富的临床经验，手术治疗子宫内膜异位症也具有良好的效果，所以说，选择任何一家医院去就医都是比较好的。

浙江中医药大学附属第二医院（浙中医大二院）/浙江省新华医院成立于1960年，原名浙江省建工医院，现为一所三级甲等中西医结合医院。浙江大学医学院附属第一医院（浙大一院）建院于1947年，是浙江大学创建的首家附属医院，现为三级甲等综合性医院。下面就为大家介绍一下这两家医院：

一、浙中医大二院

浙中医大二院看子宫内膜异位症需要挂号妇产科，该妇产科的比较优秀的医生有不少，其中就有擅长治疗子宫内膜异位症的医生，这里就为大家介绍一下浙中医大二院擅长看子宫内膜异位症的医生：

- 1.李爱萍：主任医师，熟练掌握妇产科各种常见病和疑难杂症的诊治，专长妇科生殖内分泌疾病及辅助生殖技术，擅长中西医结合治疗男性和女性不孕不育，包括男性少、弱、畸精症、性功能异常和女性卵巢功能异常、输卵管炎症阻塞、子宫内膜息肉、子宫内膜异位症等等导致的不孕，以及青春期和围绝经期相关疾病的诊治；
- 2.金丽华：副主任中医师，擅长中西医结合治疗各类妇产科内分泌疾病、妇科疼痛性疾病、炎症性疾病、产后病、产前病、盆底功能障碍性疾病等，如月经失调、子宫内膜异位症、复发性阴道炎等；
- 3.江延姣：副主任医师，专攻子宫内膜异位症、子宫腺肌症、慢性盆腔痛的临床及基础研究和妇科内镜技术。

二、浙一医院

浙一医院看子宫内膜异位症即可以找妇科医生，也可以找生殖科医生，该医院治疗子宫内膜异位症的医生是比较多的，且都比较权威，这里就为大家分享一下：

- 1.夏雅仙，妇科副主任，主任医师，擅长不孕不育，女性生殖内分泌异常导致异常子宫出血和子宫内膜异位等；
- 2.周新惠，妇科副主任，主任医师，在盆腔子宫内膜异位症、妇科良恶性肿瘤、宫颈病变、子宫内膜病变的诊治上具有丰富经验，娴熟完成各种三、四级腹腔镜手术；
- 3.林文琴：生殖医学中心科主任，主任医师，擅长治疗女性不孕不育症，人工授精，体外受精-胚胎移植，习惯性流产，多囊卵巢综合症，子宫内膜异位症，生育力评估，B超下卵巢巧克力囊肿穿刺，多胎减胎等治疗；
- 4.郑海燕，生殖中心副主任医师，擅长女性不孕症、多囊卵巢综合征、复发性流产、子宫内膜异位症等生殖内分泌疾病的诊治；
- 5.姚玲女，生殖中心副主任医师，对孕前生育力评估、子宫内膜异位症、卵巢储备下降、月经不规则、排卵障碍、多囊卵巢综合征，及其他各种因素导致的不孕不育及习惯性流产有较多的临床经验。

治疗子宫内膜异位症选择浙中医大二院和浙一医院都是可以的，不过目前浙中医大二院只开展了人工授精技术，而浙一医院不仅可以开展人工授精技术，还能开展试管婴儿技术，所以对于子宫内膜异位症不孕患者想要怀孕的话，选择浙一医院就比较合适。
